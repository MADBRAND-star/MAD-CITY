# MAD Wear Website
A ready-to-upload static website for GitHub Pages.

## Files
- index.html
- images/product-1.png through product-9.png

## WhatsApp
Every product card and button opens WhatsApp for **+255 688 525 720** with a product-specific message.

## GitHub Pages
Upload `index.html`, `product-1.png`, `product-2.png`, `product-3.png`, `product-4.png`, `product-5.png`, `product-6.png` and `product-7.png` into your repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → main → / (root).
